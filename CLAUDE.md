# Alphaday — Home

Marketing site for Alphaday, a crypto data layer. React 18 + Vite 8 + Tailwind v4, deployed as a static build.

- `yarn dev` — dev server
- `yarn build` — builds API docs, then Vite, then sitemap
- Design tokens live in [src/assets/css/alphaday.css](src/assets/css/alphaday.css) under `@theme`
- Site-wide links and content constants live in [src/config.js](src/config.js)

## Design Context

### Users

**Priority order (CEO input, 2026-08-07 — supersedes the earlier app-first ranking):**

1. **AI agent builders** — teams wiring crypto context into LLM agents. **MCP + structured, queryable data is the hook.** They evaluate on: is there an MCP server, is the schema sane, can my agent call this today, what does it cost.
2. **Developers / API consumers** — engineers integrating into bots, terminals, and dashboards. They want endpoints, docs, rate limits, and proof the data is real.
3. **App users** — people who want the Alphaday product itself: boards, widgets, dashboards. Real and valuable, but the app is the **shop window for the layer**, not the thing being pitched.

**Implication:** the homepage sells **infrastructure**. The primary action is **Start building** → `/api`. **Launch app** is the secondary path, and it functions as evidence ("the layer is good enough that we built a product on it"), not as the offer.

**MCP is the wedge.** The `<head>` meta description already leads with *"Free API & MCP, no signup"* — that is the sharpest sentence the brand says to its #1 audience, and it currently appears nowhere above the fold. Fix that before anything else.

### Brand Personality

**Three words: Bold, energetic, crypto-native.**

- Loud and high-contrast. Big type, strong color, real motion. Confidence is the trust mechanism — not restraint, not corporate polish.
- Speaks the audience's language natively. Assumes the reader knows what on-chain, governance, DeFi, and MCP mean. No explaining crypto to crypto people, no explaining tool-calling to agent builders.
- Presence over politeness. The interface should feel like it has a point of view.

### Aesthetic Direction

**Locked brand assets — do not propose replacing these:**

- **Palette:** committed dark. `--color-background: #121212`, `--color-surface: #191919`, `--color-surface-light: #242424`, `--color-surface-border: #3b3a3a`. Single accent: **Alphaday orange `#faa202`** (`--color-primary`), hover `#ffb84d`. Text `#e7e7e7`, muted `#849399`.
- **Typeface:** **Titling Gothic FB Narrow** (`--font-display` / `--font-sans`). A genuinely distinctive condensed gothic — the single strongest anti-slop asset the brand owns. **Only weights 400 (Reg) and 500 (Med) are loaded.** Anything heavier is faux-bolded by the browser and degrades the letterforms. Either load real heavy cuts or design within 400/500.
- Montserrat 600 and Open Sans are also loaded via Google Fonts — legacy, and in tension with the Titling identity.

**Anti-references — all four were selected. This is an unusually strict brief:**

- **NOT generic AI-generated SaaS.** No dark bg + glow + rounded card grid + centered hero.
- **NOT typical web3/crypto landing.** No neon gradients, 3D orbs, glassmorphism, floating token logos, "The Future of Finance" copy.
- **NOT enterprise B2B blandness.** No stock photography, no safe symmetric grids, no hedged corporate copy.
- **NOT over-designed marketing.** No scroll-jacking, no parallax, no animation for its own sake. Motion must carry meaning.

**The anti-slop requirement is now a credibility requirement, not a taste preference.** Alphaday sells infrastructure to people who build with AI. A homepage that looks like it was generated by AI tells that exact audience the team has no craft. They are the single group most fluent in these tells.

The narrow lane between the four anti-references: **loud but earned.** Bold typography and strong color doing real informational work, with nothing decorative surviving the cut.

### Design Principles

1. **Hierarchy follows the audience: agent builders first.** The boldest element on the page should push toward the API and MCP. If the eye lands on the consumer app first, the page is miscalibrated.

2. **Loud through type and color, never through effects.** The brand's boldness comes from Titling Gothic at scale and decisive orange. Glow, blur, gradient, and shadow are the web3/AI-slop vocabulary the brief explicitly rejects — reach for size, weight, and contrast instead.

3. **Orange means "act."** A single accent on a dark field is a precision instrument. Every non-interactive element wearing orange dilutes the CTA. Spend it on actions and one hero moment, not on labels, list items, and decoration.

4. **Diagram the mechanism — don't decorate it.** For agent builders the architecture *is* the product, so a pipeline schematic is legitimate hero content (this would be wrong for a consumer audience). But it has to be an honest schematic: real data types, real outputs, real protocol names. The moment it becomes chips-and-glow it stops being a diagram and becomes ornament.

5. **Show, don't claim.** For technical buyers a working `curl`, a real JSON response, or an MCP config block outperforms any adjective. Caveat: monospace is not a substitute for substance — only show code that actually does something. Don't use a terminal aesthetic as "technical vibes" decoration.

6. **Respect the loaded weights.** Design within Titling Gothic 400/500 — or ship the real bold cuts. Faux bold on a condensed gothic is visible and cheap-looking, and it undermines the one asset that makes this site look non-generic.

7. **Every element justifies its existence.** With all four anti-references in play, the default answer to "should we add this?" is no. Subtract before adding.
